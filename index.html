Como Publicar no GitHub Pages

Este é um aplicativo Single File (HTML + JS + Tailwind CSS). Siga os passos abaixo para hospedá-lo gratuitamente no GitHub Pages:

  1. Crie um Repositório no GitHub:

    Acesse o GitHub e crie um novo repositório público (ex: chat-atendimento).

  2. Adicione o Arquivo:

    Salve todo o código deste arquivo exatamente com o nome index.html e faça o upload/push para a branch principal (main ou master).

  3. Ative o GitHub Pages:

    No repositório, vá em Settings > Pages. Em Source, selecione Deploy from a branch, escolha a branch main e clique em Save.

  4. Pronto!

    Em cerca de 1 a 2 minutos seu chat estará online no endereço https://seu-usuario.github.io/chat-atendimento/.

Dica de Teste: Abra duas janelas do seu navegador (uma como Cliente e outra como Atendente). Como o código utiliza BroadcastChannel, as mensagens e a fila são sincronizadas em tempo real entre as abas!
